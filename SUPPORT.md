# Support

Start with [Installation and removal](docs/installation.md), including
[health and recovery](docs/installation.md#health-and-recovery).

- Ask questions and share ideas in [Discussions](https://github.com/JBallin/ballin-scripts/discussions).
- Report bugs in [Issues](https://github.com/JBallin/ballin-scripts/issues). Include
  the command, expected and actual behavior, and relevant sanitized output.
- Report suspected security vulnerabilities privately using the
  [security policy](SECURITY.md). Do not post vulnerability details, credentials,
  or sensitive backup contents in public issues, discussions, or pull requests.
