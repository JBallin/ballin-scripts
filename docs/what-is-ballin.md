# What is Ballin?

People who build software use many tools on their Macs. Keeping those tools
current and remembering how they were set up can take time. Ballin brings
routine upkeep together and can save useful information for later.

## Keeping a Mac current

Ballin runs updates for supported tools in one place, reducing repetitive work.
For example, with an optional helper installed, it can update installed apps
from the Mac App Store. It can also run updates for developer tools and macOS;
which updates run depends on the available tools and settings.

## Remembering a setup

Ballin can save selected tool lists and settings, such as installed editor
extensions or editor preferences. When setting up another Mac, someone can use
that record to help choose what to install and configure. It is a reference for
parts of the working setup, not a backup of the whole computer or an automatic
way to set up the new Mac.
