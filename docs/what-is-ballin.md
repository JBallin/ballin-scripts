# What is Ballin?

People who build software use many tools on their Macs, and keeping them updated
can be repetitive. Ballin brings routine updates for supported tools together,
so there is less to do by hand.

For example, with an optional helper installed, Ballin can update installed apps
from the Mac App Store. Which updates run depends on the available tools and
settings.

You can use Ballin for updates without backups. If enabled, backups can save
selected tool lists and settings as a reference when setting up another Mac.
The person still does the setup themselves: Ballin does not automatically
set up the new Mac or back up the whole computer.
