## Finding: active preference discovery

`commands/backup_scope.json` still names
`.ballin-scripts/ballin.config.json`. `portableConfigSnapshot` in
`commands/backup_snapshots.ts` uses that path even for packaged installations,
whose prototype config lives in `~/.ballin`.

The source-discovery probe verified both outcomes:

1. With only package config, `ballin_config` is reported absent.
2. With package config plus a synthetic Git config, discovery selects the Git
   config and prepares its collector arguments.

No collector executed. The correction must make backup preference discovery use
the active resolved configuration, with package-only and coexistence regression
cases. Installation/upgrade success does not establish package backup correctness.

## Architecture policy for the next candidate

Retain the direct route for native Apple Silicon and Intel Macs meeting Ballin's
macOS/runtime requirements. Current Quickstart explicitly handles `arm64` and
`x86_64` and requires macOS 13.5 or newer. Node.js 26.13.0 documents macOS x64
13.5+ as Tier 2 and arm64 13.5+ as Tier 1. Homebrew's narrower support must not
silently remove Ballin's independent Intel route.

Offer new Homebrew bootstrap only on environments supported by the current
upstream installer. Its current macOS script rejects Intel, and its support guide
says new Intel bottles are no longer built. Do not use an obsolete installer or
force source builds to bypass that boundary. Existing usable Intel Brew remains
an optional integration subject to explicit capability/version checks; do not
promise that all current formulae will install. Existing installations and new
bootstrap have different requirements.

Prefer native execution on Apple Silicon; identify translated execution rather
than mistake Rosetta for native Intel hardware. A translated run is not native
Intel validation. Native Intel end-to-end installation remains a recorded gap;
obtain that evidence before calling the Intel candidate fully validated. This
policy preserves the current route without claiming every old Mac or unsupported
macOS release works.
