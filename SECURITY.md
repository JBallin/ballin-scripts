# Security Policy

## Reporting a Vulnerability

If you discover or suspect a security vulnerability in this repository, please report it privately. **Do not create a public issue, discussion, or pull request containing vulnerability details, credentials, or sensitive backup contents.**

### How to Report Privately

Please submit all security advisories privately via GitHub:

👉 **[Report a vulnerability](https://github.com/JBallin/ballin-scripts/security/advisories/new)**

### What to Include in Your Report

To help us review and triage the report effectively, please include:
- **Affected Revision:** The specific commit hash, branch, or release tag where the issue was observed.
- **Security Boundary:** The expected vs. actual behavior and security boundary breached.
- **Impact:** What an attacker or unauthorized user could achieve with this issue.
- **Sanitized Reproduction:** Step-by-step reproduction instructions or a proof-of-concept (PoC) with all tokens, credentials, and private backup paths scrubbed.

Thanks for helping keep Ballin secure.
